# 계약현황 정리 도우미

엑셀 계약 목록을 **내 브라우저에서 확인하고 정리**하는 앱입니다. 설치나 회원가입이 필요 없으며, 원본 파일을 덮어쓰거나 어디론가 자동 제출하지 않습니다.

### ➜ [앱 바로 열기](https://ssinmia-bit.github.io/work/)

처음 열면 **2026년 교육용 계약 20건**이 미리 표시됩니다. 이 자료는 실제 업체·계약 정보가 아닌 예시입니다.

## 사용 방법

1. 위 링크를 열고 화면에 표시된 20건 예시와 결과 미리보기를 살펴봅니다.
2. 내 엑셀을 확인하려면 **「엑셀 파일 선택하거나 여기에 놓기」**를 누르거나 `.xlsx` 파일을 점선 상자로 끌어다 놓습니다. 파일은 한 번에 하나씩 선택합니다.
3. 미리보기에서 **「확인 필요」** 항목을 살펴본 뒤 **「작업용 엑셀 저장」**을 누릅니다. 새 파일은 브라우저의 다운로드 폴더에 저장됩니다.
4. 저장한 결과를 원본과 대조하고, 필요한 정보는 직접 확인한 뒤 사용합니다.

## 어떤 엑셀을 처리하나요?

| 파일 종류 | 앱이 하는 일 | 저장되는 파일 |
| --- | --- | --- |
| **원본 7열** | `계약일자·계약명·시작일·종료일·계약금액·업체명·세부사업`을 읽고, 세부사업 코드를 **예산세부사업과 세목**으로 나눕니다. 원본에 없는 계약구분은 `확인 필요`로 남깁니다. | `계약현황_작업용.xlsx` |
| **작성완료 14열** | 계약구분·사업자번호·연락처 등을 포함한 **14개 항목을 유지**하며 검토합니다. 확인 사항이 있으면 마지막 열에 사유를 적습니다. | `계약현황_검토본.xlsx` |

예를 들어 원본의 `세부사업`이 `2231-304-420-02`라면 **예산세부사업 `2231-304` / 세목 `420-02`**로 나눕니다. 형식이 맞지 않거나 빈칸인 값은 임의로 채우지 않습니다.

## 알아둘 점

- `.xlsx` 파일만 지원합니다. 파일 크기는 **10MB 이하**, 데이터는 **1만 행 이하**로 사용해 주세요.
- 웹 페이지는 GitHub에서 제공하지만 **선택한 엑셀의 읽기·변환은 브라우저 안에서 처리**하며, 앱에 서버 업로드 기능은 없습니다. HTML 한 파일 안에 코드와 예시 자료가 들어 있습니다.
- 인터넷이 어려운 환경이라면 이 저장소의 `index.html` 파일을 PC에 저장한 뒤 **크롬·엣지에서 직접 열어** 사용할 수 있습니다. 이때도 별도 서버나 인터넷 연결이 필요하지 않습니다.
- **업무포털 DOCX에서 정보 자동 추출, 기존 연도별 시트 병합, 상위부서 자동 제출은 지원하지 않습니다.** 실제 기관 자료에 적용하기 전에는 소속 기관의 보안·개인정보·자료 사용 승인 절차를 먼저 확인해 주세요.
